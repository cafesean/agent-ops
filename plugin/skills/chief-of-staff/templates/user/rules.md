# User rules

This folder is your user layer: your own standing rules and scripts for the agent-ops chief of staff. It lives
outside the plugin, so plugin updates never touch it. The chief reads this file right after STATE.md; every worker
is told to read it in turn 1. Keep each rule one line, in your own words. A rule here wins over a plugin default,
except the one-way-door rules (those always need you).
